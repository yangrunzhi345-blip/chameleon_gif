## 1.1 项目概述

**Chameleon Gif** 是一款现代化、高性能、跨平台的 **MP4 / 多图片 → GIF** 工具。

用户选择任意 MP4 视频,通过可视化时间轴设定起止区间,调节帧率、尺寸等参数,即可快速导出高质量 GIF;也支持选择多张图片按顺序合成为帧动画 GIF(调节帧率、每图停留时长、循环与质量),并支持**每张图片的独立精细控制**(等比缩放倍数 / 宽度 / 高度,不扭曲、透明填充);支持导出记录管理与批量转换。

- **项目代号**:Chameleon Gif
- **技术底座**:Flutter + Dart + FFmpeg(详见 [03-技术选型](03-技术选型.md))
- **仓库**:Git 管理,开发规范见 [11-开发规范](11-开发规范.md)

## 1.2 愿景与目标

### 愿景
让"视频转 GIF"从命令行工具变为**人人可用的现代化桌面应用**:所见即所得的预览、专业级的调色板优化、跨平台一致的体验。

### 项目目标
| 目标 | 说明 |
|------|------|
| 专业级 GIF 制作 | 两遍调色板法(Palette)、Dithering、色彩数量控制(第二期) |
| 跨平台 | Linux / Windows / Android 首发,macOS / Web 预留(第三期) |
| 高性能 | FFmpeg 原生转码、Isolate 解耦、流式进度,500MB 视频流畅操作 |
| 易扩展 | 五层架构 + 模块化,转码引擎接口化,支持新增格式(WebP/APNG) |
| UI 现代化 | Material 3、深色模式、响应式三栏布局 |

## 1.3 平台矩阵

| 平台 | 状态 | 说明 |
|------|------|------|
| Linux | ✅ 首发(主要开发平台) | AppImage + deb 分发 |
| Windows | ✅ 首发 | NSIS 安装包 |
| Android | ✅ 首发 | APK/AAB,触屏布局 |
| macOS | 🔒 预留(V3) | 架构已兼容,待补签名与公证 |
| Web | 🔒 预留(V3) | 转码走 WASM,需独立打包体积评估 |
| iOS | 🔒 预留(V3 之后) | 转码走 ffmpeg_kit_flutter,评审后引入 |

> 平台预留的前提:**FFmpegEngine 接口已抽象平台差异**(见 [08-FFmpeg设计](08-FFmpeg设计.md)),新增平台仅需新增 PlatformAdapter 实现。

## 1.5 目标用户

1. **内容创作者 / 自媒体运营**:制作表情包、教程动图、社区贴图
2. **设计师 / 产品人员**:快速将交互录制转为演示 GIF
3. **普通用户**:视频片段转 GIF 分享
4. **开发者**:批量处理、脚本化(经 CLI 预留接口,V3)

## 1.6 竞品定位

| 竞品 | 形式 | 我们的差异点 |
|------|------|--------------|
| Ezgif / 在线工具 | Web | 无隐私风险(本地转换)、可离线、无文件大小限制 |
| Gifski | 单功能 | 时间轴裁剪、批量队列、历史记录、跨三平台 |
| ScreenToGif | 录屏为主 | 专注视频转 GIF、调色板优化更专业 |
| ffmpeg 命令行 | CLI | 可视化预览与参数调节、零学习成本 |
