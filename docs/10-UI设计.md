# 10 UI 设计

> 需求:[02-需求分析](02-需求分析.md) · 状态管理:[09-状态管理](09-状态管理.md)

## 10.1 设计原则

1. **Material 3** 全面采用:`ColorScheme.fromSeed` 动态配色、组件化(NavigationRail/FilledButton/Slider/SnackBar)
2. **三平台一致的信息架构**,布局随屏幕宽度自适应(桌面三栏 / 窄屏单列)
3. **深色模式**三态(浅/深/跟随系统),色板由 seed 派生,无硬编码颜色
4. **高 DPI 与窗口缩放**:依赖 MediaQuery 的 DPI 感知、`devicePixelRatio` 图标资源(使用 Material 内建矢量图标,天然无损);桌面窗口缩放时布局重排而非拉伸
5. **极简聚焦**:主界面只有"导入→预览→参数→导出"一条主线,历史与设置收敛到侧栏

## 10.2 布局体系

### 断点规则(响应式)

| 断点 | 形态 | 适用 |
|------|------|------|
| `< 600dp` | 单列 + NavigationBar | Android 竖屏 |
| `600–1024dp` | 双栏(内容+参数抽屉) | Android 横屏/小平板 |
| `> 1024dp` | 三栏(侧栏+预览+参数) | Linux/Windows 桌面 |

### 10.2.1 Linux / Windows 桌面布局(三栏)

```
┌──────────┬───────────────────────────────┬────────────────────┐
│ NavigationRail │   预览区               │   导出参数面板       │
│            │                            │                    │
│  ⌂ 主页   │   ┌───────────────────┐     │  FPS      [15] ▾   │
│  🕘 历史   │   │                   │     │  尺寸    [480] ▾   │
│  ⚙ 设置   │   │   VideoPlayer     │     │  循环    [0=∞]     │
│            │   │   (填充区域)      │     │  开始  00:03.200  │
│            │   └───────────────────┘     │  结束  00:09.500  │
│  ────────  │   [▶ 播放] [⏸ 暂停] [⟲]  │  导出目录 [~/GIF]  │
│  最近列表  │   ┌───────────────────┐     │                    │
│  (历史)    │   │ 时间轴            │     │ ┌────────────────┐ │
│            │   │ ▐▌====[===]====== │     │ │ 导出 GIF       │ │
│            │   │ 00:03.2  00:09.5  │     │ └────────────────┘ │
│            │   └───────────────────┘     │  预估大小 2.4MB   │
└──────────┴───────────────────────────────┴────────────────────┘
```

- 三栏可拖拽调整宽度(最小宽:侧栏 200 / 预览 480 / 参数 320)
- 侧栏可折叠;导出中在参数面板显示进度条与取消按钮
- 窗口缩放:由 Flutter 自适应布局,`minSize` 桌面约束 960×640

## 10.3 关键页面设计

### 10.3.1 主页(转换工作台)

| 元素 | 行为 |
|------|------|
| 空态 | 无视频时居中大按钮"导入 MP4"(支持拖拽,V2)+ 使用提示 |
| 预览区 | media_kit Video widget;画面按 fit 填充;失败显示错误视图 |
| 时间轴 | 起止双句柄;拖动句柄实时 seek 预览;选区高亮;`I`/`O` 快捷键 |
| 参数面板 | 分组:输出(帧率/尺寸/循环)/ 时间(起止)/ 目录(选择按钮+路径) |
| 导出按钮 | 常驻底部;点击后校验(起点<终点、文件存在) → 入队 |
| 进度条 | 转换中替换导出按钮:百分比 + 预估剩余 + 取消 |

### 10.3.3 历史列表(侧栏/页)

- 每项:缩略图(首帧,ImageCache 缓存)、文件名、时间、大小;右键/长按:重转、删除、打开位置
- 空态文案引导;清空二次确认

### 10.3.4 图片制作 GIF 页(`/image-gif`)

- 布局与 [10.2] 断点一致:宽屏(≥1024)双栏(左 380px 图片列表 + 右参数表单);窄屏上下排(列表固定 260px 高)
- 左栏列表项:48px 缩略图(Image.file + errorBuilder)、文件名、**操作区从左到右 = [精细控制信息, 齿轮, 下移, 上移, 删除]**(齿轮 tooltip"精细化控制",转换中禁用;信息仅该图已操作时显示,如"缩放倍率:2 宽度:480",maxWidth 120 + ellipsis 防溢出)
- 右栏参数表单:帧率下拉 / 每图停留时长(毫秒,TextInput)/ 缩放倍数下拉(含自定义 0.1–4)/ 宽度 / 高度(0 = 原图等比 + 自定义 1–4096)/ 循环 / 质量开关 / 导出目录 / 开始转换
- 列表操作(上移/下移/删除/追加)同步每图控制数组(控制随图走);首图尺寸探测驱动倍数联动与画布

### 10.3.5 精细化控制页(`/image-control`,单张图片)

- 样式与"导入 MP4 预览工作台"一致:宽屏左预览右参数(右栏 360px),窄屏上下排;**无播放进度条、无时间轴**
- 预览区:画布比例框(`AspectRatio(canvasW/canvasH)`,画布来自全局表单/首图尺寸)+ 深色棋盘底(示意透明 pad 区),图片按 `controlTarget`(与命令构造同规则)呈现最终效果 —— 控制变化实时刷新,所见即所得
- 参数面板:等比缩放倍数(默认 1,下拉 + 自定义 0.1–4)/ 宽度(默认 0 = 该图自身比例)/ 高度(默认 0);三个控件相互独立;底部"恢复默认"(重置 1/0/0)+ "保存"(pop 返回 PerImageControl)
- 语义提示文案:"宽度与高度均指定时按精确尺寸(允许变形);仅倍率或单边保持该图比例";该图源尺寸探测失败 → 禁用编辑并提示
- 进入方式:图片列表齿轮 → `context.push('/image-control', extra: Map)`(JSON 基础类型,go_router 恢复安全);返回经 `Navigator.pop(PerImageControl?)`(null = 未保存)

## 10.4 主题系统

| 项 | 实现 |
|----|------|
| 色彩 | `ColorScheme.fromSeed(seed: 品牌色)`;动态取色(Android 12+,可选开关) |
| 深色模式 | `ThemeMode.system/light/dark`,持久化于 SharedPreferences |
| 文字 | 跟随系统字体;缩放随 `textScaler` |
| 组件 | Material 3 全组件(无旧版 Material 2 组件) |
| 高 DPI | 矢量图标 + `ImageCache.maximumSizeBytes` 调高(大图预览) |

## 10.5 无障碍与可用性

- 对比度:M3 色板保证 AA 级;深色模式同步
- 键盘:空格播放/暂停、`I`/`O` 设起止、`Ctrl+O` 导入、`Ctrl+E` 导出、Esc 关闭弹窗
- 焦点遍历顺序与视觉顺序一致;所有图标按钮有 tooltip

## 10.6 设计规范落地

- 页面骨架:桌面 `ResponsiveBuilder`(自定义,读 MediaQuery 断点)→ 三栏/双栏/单列
- 组件库:shared/widgets(进度条、空态、错误视图、参数行)统一封装,禁止页面内重复手写
- 图标:Material Icons;品牌图标 V3 引入
