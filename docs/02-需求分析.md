## 2.1 需求分级原则

- **P0(强制)**:MVP 必须交付,缺失即不合格

**MVP 验收场景(用户故事)**
1. 用户打开应用 → 点击"导入视频" → 选择 1.mp4 → 预览立即播放
2. 用户在时间轴拖动 → 设定 0:03–0:09 → FPS=15、宽度=原图等比 → 点击导出
3. 进度条从 0% 增长到 100% → 弹出完成提示 → 点击"打开文件夹" → 找到 out.gif
4. 中途点击"取消" → 转换终止,无残留临时文件
5. 用户选择 1024×1024 与 1080×1920 两张图 → 合成 GIF:两图均保持自身比例、居中、空余透明,不扭曲
6. 用户对第 2 张图点齿轮 → 精细控制页设宽度 480 → 保存 → 该图按 480 等比显示,第 1 张图不受影响;齿轮左侧实时显示"宽度:480"

## 2.5 非功能需求

| 类别 | 需求 | 验收标准 |
|------|------|----------|
| 性能 | 启动时间 | 冷启动 ≤ 2s(桌面,SSD) |
| 性能 | 预览流畅度 | 1080p 播放 ≥ 55fps;UI 操作不因转码卡顿(转码在独立进程) |
| 性能 | 大文件支持 | 500MB MP4 可导入预览,内存峰值 ≤ 1.5GB |
| 跨平台 | 行为一致性 | 三平台同一版本同一参数输出结果一致(字节级校验 CLI 同参输出) |
| 可用性 | 反馈 | 任何耗时操作 > 1s 必须有进度或忙碌指示 |
| 健壮性 | 崩溃率 | 无异常崩溃;转换失败不残留临时文件 |
| 隐私 | 本地处理 | 全程本地转码,无任何上传 |
| 可维护性 | 静态分析 | `flutter analyze` 零告警 |
| 可测试性 | 核心单测 | CommandBuilder / ProgressParser 覆盖率 ≥ 80% |
