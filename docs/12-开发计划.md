# 12 开发计划

> 需求:[02-需求分析](02-需求分析.md) · 风险:[13-风险分析](13-风险分析.md) · 测试:[14-测试计划](14-测试计划.md) · 发布:[15-发布计划](15-发布计划.md)

## 12.1 计划总览

- 团队规模:1 名开发者 + AI 辅助(Claude Code / DeepSeek)
- 工期估算:单阶段乐观值~保守值;合计 **约 38 天(6–7 周)**
- 里程碑:MVP(P0–P4 + P5)→ V2(P6–P8)→ 发布(P9)
- 依赖关系:P0 前置一切;P1→P2→P3 串行(转换链路);P4 与 P5 可并行;P6 依赖 P3/P4

## 12.2 阶段计划明细

### P0 基础架构(3–5 天)

| 项 | 内容 |
|----|------|
| 工作内容 | 工程脚手架、目录结构(已完成,见 [05-目录结构](05-目录结构.md))、分层骨架、Isar/Logger/MediaKit 初始化、路由表与主题、CI(analyze/test) |
| 涉及模块 | app、storage、log、theme、task_queue(骨架) |
| 风险 | 依赖版本冲突(已解:SDK 3.44.8);Isar 与 Freezed 生成器配合 |
| 完成标准 | 空应用三平台可运行;analyze 零告警;CI 模板就绪 |
| 验收标准 | Linux 启动 → 深色切换生效 → 主题/语言持久化 |

### P1 视频解析(3 天)

| 项 | 内容 |
|----|------|
| 工作内容 | ffprobe 信息抽取(经 ffmpeg_kit_flutter_minimal 的 FFprobeKit)时长/分辨率/帧率/编码;VideoInfo 模型(Freezed);解析错误分类 |
| 涉及模块 | import、converter(ffprobe 封装)、domain |
| 风险 | 异常视频(损坏/无头信息)解析失败率 |
| 完成标准 | 解析 10 个真实视频样本 100% 返回正确元数据;损坏文件给出明确错误 |
| 验收标准 | 单测:已知视频断言时长/尺寸;损坏样本断言 SourceBrokenException |

### P2 视频预览(4 天)

| 项 | 内容 |
|----|------|
| 工作内容 | PlayerController 生命周期封装;播放/暂停/seek/静音;播放器错误呈现;空态与加载态 |
| 涉及模块 | preview、app(路由) |
| 风险 | media_kit Linux 渲染环境差异(硬件加速回退软件渲染) |
| 完成标准 | 三平台播放流畅(1080p ≥ 55fps);切视频无泄漏(PlayerController dispose) |
| 验收标准 | Widget 测试:加载→播放→暂停→seek 状态正确;集成测试播放真实视频 |

### P3 GIF 导出(5 天)⭐

| 项 | 内容 |
|----|------|
| 工作内容 | CommandBuilder(标准+palette 两遍)、FFmpegKitEngine(ffmpeg_kit_flutter_minimal)、ProgressParser、ErrorHandler、CancellationManager、TaskManager 状态机、进度 UI、完成通知 |
| 涉及模块 | converter、task_queue、export、storage |
| 风险 | FFmpeg 参数细节(滤镜链顺序、palette 质量);取消竞态;进度解析鲁棒性 |
| 完成标准 | 参数→命令单测全绿;端到端:导入→默认参数→导出成功;取消无残留;输出与 CLI 同参一致(SHA-256) |
| 验收标准 | 集成测试:3 段不同视频导出成功且可播放;取消测试无临时文件残留 |

### P4 参数调节(4 天)

| 项 | 内容 |
|----|------|
| 工作内容 | 时间轴(双句柄+快捷键)、起止时间设置、FPS/尺寸/循环、导出目录选择与持久化、表单校验、参数→预估 |
| 涉及模块 | timeline、export、settings |
| 风险 | 时间轴拖动与预览 seek 的流畅联动 |
| 完成标准 | 全部 MVP 参数项可用;校验边界(起点≥终点自动交换等);默认参数持久化 |
| 验收标准 | Widget 测试:拖拽句柄改选区;命令快照断言参数正确 |

### P5 历史记录(3 天)

| 项 | 内容 |
|----|------|
| 工作内容 | Isar 集合(History/Task)、仓储实现、历史列表/详情/重转/删除、缩略图缓存 |
| 涉及模块 | history、storage、domain |
| 风险 | Isar schema 冻结期结构变更 |
| 完成标准 | 历史 CRUD 全通;完成转换自动入库;重转回填参数 |
| 验收标准 | 单测:仓储 CRUD;Widget:列表渲染与空态 |

### P6 批量导出(5 天)

| 项 | 内容 |
|----|------|
| 工作内容 | 多选导入、任务队列并发(2)、任务列表 UI、单个取消/全部取消、失败重试(指数退避)、崩溃恢复 |
| 涉及模块 | import(多选)、task_queue、export |
| 风险 | 并发时进度流交错;恢复重复入队 |
| 完成标准 | 并发 2 正确;单任务失败不影响队列;重启恢复 queued/running |
| 验收标准 | 压力:8 任务并发调度无状态错乱;恢复测试:杀掉进程重启队列复原 |

### P7 性能优化(4 天)

| 项 | 内容 |
|----|------|
| 工作内容 | 转码进度流节流、UI 帧率优化、缩略图 ImageCache 调优、isolate 化(命令构造/日志解析)、启动速度(延迟加载非首屏模块)、内存采样基线 |
| 涉及模块 | 全局 |
| 风险 | 过度优化返工 |
| 完成标准 | 指标达标(见 [02-需求分析](02-需求分析.md) §2.5);启动 ≤2s |
| 验收标准 | 性能基准记录:转码中 UI 保持 55fps;500MB 视频内存峰值 ≤1.5GB |

### P8 测试补齐(4 天)

| 项 | 内容 |
|----|------|
| 工作内容 | 单测覆盖率补齐(核心 ≥80%)、Widget 覆盖、integration_test 全链路、跨平台手工清单(三平台) |
| 涉及模块 | 全部 |
| 风险 | 测试环境差异(Android 模拟器与桌面) |
| 完成标准 | [14-测试计划](14-测试计划.md) 全部用例执行通过 |
| 验收标准 | CI 全绿;三平台手工清单签字 |

### P9 发布(3 天)

| 项 | 内容 |
|----|------|
| 工作内容 | Linux AppImage+deb、Windows NSIS、Android APK/AAB;图标/版本号;安装包冒烟;发布文档(见 [15-发布计划](15-发布计划.md)) |
| 涉及模块 | 工程/打包 |
| 风险 | 打包工具链平台差异;Android 原生库打包体积 |
| 完成标准 | 三平台安装包安装即用(FFmpeg 内嵌);版本号/升级路径正确 |
| 验收标准 | 三平台全新机器安装 → 完整转换流程通过 |

## 12.3 里程碑与节奏

```
W1  P0 基础架构
W2  P1 视频解析 + P2 视频预览(部分)
W3  P2 完成 + P3 GIF 导出(核心链路)
W4  P3 完成(调色板/取消)   ← 首个可演示里程碑(MVP 骨架)
W5  P4 参数调节 + P5 历史
W6  P6 批量导出            ← MVP 完成里程碑
W7  P7 性能 + P8 测试
W8  P8 收尾 + P9 发布       ← V1.0 发布
```
