## 14.1 测试金字塔与策略

```
          ╭───────────────╮
          │ 集成测试(E2E) │  ← 三平台真实转换链路(少而关键)
          ├───────────────┤
          │  Widget 测试  │  ← 页面与状态绑定(中等)
          ├───────────────┤
          │   单元测试    │  ← 纯函数核心(最多、最快)★
          ╰───────────────╯
        + 性能/压力测试 + 跨平台手工清单
```

- **原则**:核心逻辑(CommandBuilder/ProgressParser/状态机)必须纯函数化以支撑单元测试;UI 层只测行为不测像素
- **两层分离与测试分工**:功能层(application)用例/控制器用纯 Dart 单测(`ProviderContainer`,无 Widget 依赖,快速);UI 层(presentation)仅 Widget 测试验证行为。业务逻辑若"只能靠 Widget 测试覆盖"即视为违反分离红线
- **统一约定**:`test/` 镜像 `lib/` 结构;测试用例中文命名,`testWidgets` 中设置 `surfaceSize` 模拟桌面尺寸

| LogParser | stderr 分级;长行截断 | 纯函数 |

> **已知偏差(2026-08 审查后确认)**:shared/platform 下执行器(process_engine、

## 14.4 集成测试(integration_test)

| 场景 | 步骤 | 断言 |
|------|------|------|
| 全链路转换(冒烟) | 夹具视频 → 导入 → 默认参数 → 导出 → 完成弹窗 | 输出存在、可被解码、弹窗正确 |
| 取消链路 | 大视频导出中取消 | 任务 cancelled;临时文件目录为空 |
| 崩溃恢复 | 注入"模拟中断"(kill 子进程)→ 重启 | queued/running 任务重新排队并完成 |
| 批量队列 | 3 任务并发 2 | 状态流正确;全部完成;历史 3 条 |
| 连续切换视频 ×10 | 循环导入/释放 | 无内存泄漏(内存基线内) |
| 图片合成 GIF | 夹具图片(64×64 纯色 ×3)→ 图片制作页 → 转换 → 完成弹窗 | 输出存在、可被解码、帧数 ≈ fps×N×每图时长 |
| 图片不扭曲 | 不同宽高比夹具图(1024² + 1080×1920 + 200²)→ 默认参数转换 | 输出画布恒一致;各帧角点 alpha=0(透明 pad);图内容保持自身比例(无拉伸) |
| 每图精细控制 | 齿轮 → 控制页设某图宽度/倍率 → 保存 → 转换 | 该图按控制目标呈现(双边变形/单边等比),其余图默认链不受影响;任务/历史持久化可重转复现 |
| 拍摄链路(采集 → GIF) | fake CameraPort 拍摄 → 产物落 capturesDir → 自动导入 → 转换(capture_flow_test) | 产物存在、自动进 /preview、导出完成;历史可重转 |
| 桌面拍摄预览 | 桌面 ffmpeg 采集实时预览与拍摄产物校验(desktop_preview_capture_test,需环境相机/虚拟设备) | 预览流可达;产物时长与设定一致 |
| Android 相册桥 | MediaStore saveVideo/saveGif 通道往返(android_media_store_bridge_test) | 通道调用正确;结果三态映射 |
| 录屏实测(桌面) | x11grab/wf-recorder 真实录制(单测目录 test/features/screen_record 实测套件,含 Wayland 加固) | 产物可被 ffprobe 解析、时长达标;取消/区域参数正确 |

> **采集相关补充(2026-08-06 落地)**:相机/录屏的纯逻辑(命令装配/区域几何/环境探测/v4l2 解析)在 `test/features/camera/` 与 `test/features/screen_record/` 单测覆盖(快照测试锁命令格式);桌面真实采集实测(X11/Wayland)同目录实测套件执行,环境不具时自动跳过。

夹具:`test/fixtures/` 用 FFmpeg 生成的小样本(3s 640×360 彩条+运动;图片模式另含 `images/` 下 64×64 纯色 PNG ×3),提交到仓库(体积 <1MB)。图片命令构造快照测试见 §14.2(`image_command_builder_test.dart`,含默认链/控制链快照与 `control_target` 预览规则),真机命令验证:输出 GIF 时长精确 = Σ每图时长、帧数精确 = fps×总时长(ffmpeg 8 已实测;透明 pad 链两遍 EXIT=0、角点 alpha=0 实证)。

**2026-08-06 新增单测**:`per_image_control_test`(isDefault/JSON 往返/summary)、`image_command_builder_test` 控制链 7 例(双边变形/单边等比/倍率表达式/min 钳制/退化/全默认≡null)、`schemas_test` 每图控制往返、`task_manager_test` 持久化/崩溃恢复/重试穿透、`history_controller_test` 重转复现、`image_gif_screen_test` 齿轮与信息显示(含控制随图走)、`image_control_screen_test` 7 例(渲染/保存返回/恢复默认/初始回显/探测失败禁用/画布未知)。

## 14.7 CI 流水线(触发:push/PR)

```
1. flutter pub get
2. dart format --output=none --set-exit-if-changed .
3. flutter analyze(零告警)
4. flutter test(Linux 容器)
5. (可选,标签触发) flutter build linux --release + 集成测试
```

- Android 单测在 CI 容器内跑(无模拟器);Android E2E 走发布前手工/夜跑清单
- Windows 构建:release 标签触发(需 Windows runner,V2 接入)
