# 13 风险分析

> 开发计划:[12-开发计划](12-开发计划.md) · 测试:[14-测试计划](14-测试计划.md)

## 13.1 风险矩阵

| 等级 | 概率×影响 | 处理 |
|------|-----------|------|
| 🔴 高 | 影响重大且概率高 | 立即缓解,有预案 |
| 🟡 中 | 影响中等 | 缓解 + 监控 |
| 🟢 低 | 影响有限 | 接受 + 常规监控 |

## 13.2 风险清单

### R-01 🔴 FFmpeg 平台/版本差异

- **描述**:不同平台(含 Android 的 FFmpeg 构建差异)在滤镜、参数行为上的差异,导致输出不一致;未来 FFmpeg 版本升级引入行为变化
- **概率** 高 · **影响** 高
- **缓解**:
  1. 三平台共用同一转码库版本(ffmpeg_kit_flutter_minimal,内置 FFmpeg),版本锁定
  2. 跨平台输出一致性测试:SHA-256 对比同参输出(见 [14-测试计划](14-测试计划.md) §14.6)
  3. CommandBuilder 命令快照测试,参数变更即暴露
- **预案**:发现平台差异 → 记录差异矩阵 → 在 CommandBuilder 生成平台特定参数(经 PlatformAdapter 标志)

### R-02 🔴 Android 后台任务被系统回收

- **描述**:转码中应用退到后台,Android 进程被回收导致转换中断
- **概率** 中(长时间转码) · **影响** 高(数据丢失/用户信任)
- **缓解**:
  1. 任务状态持久化(Isar),重启自动恢复(queued→running 重置)
  2. 前台服务通知(V2 批量场景):持续通知 + 可取消按钮
  3. 转换前检查 `isDeviceInteractive`/充电状态提示(可选)
- **预案**:回收 → 下次启动恢复队列;输出半成品标记 failed 并可重试

### R-03 🟡 大文件转码内存与磁盘占用

- **描述**:长时间/高分辨率视频转码时,中间文件(palette、反向缓存)与内存峰值超预期
- **概率** 中 · **影响** 中
- **缓解**:Reverse(倒放)仅 V2 且加缓存上限提示;输出前预估剩余磁盘(ErrorHandler 的 DiskFull 提前检测);WorkDir 用系统临时目录(自动清理)

### R-04 🟡 Isar 官方稳定版停滞(3.1.0 长期无更新,4.x 仅 dev)

- **描述**:Isar 生态维护节奏放缓,官方 3.1.0 生成器与现代化工具链(source_gen ≥4)不兼容
- **概率** 已发生 · **影响** 中(重写仓储代价高)
- **缓解(已执行)**:
  1. **已切换到 community fork**:`isar_community` / `isar_community_flutter_libs` / `isar_community_generator` ^3.3.2(2026-03 更新,API 兼容,import `package:isar_community/isar.dart`),解决生成器冲突
  2. 仓储接口(domain)与实现完全隔离,可整体替换
  3. 持续观察:官方 4.0 稳定后再评估是否回归官方
  4. schema 冻结期(MVP)内不改结构
- **预案**:替换为 drift/sqflite 时,仅重写 shared/repositories(接口不变,业务无感)

### R-05 🟡 media_kit 桌面渲染兼容性

- **描述**:Linux 不同发行版(缺 libmpv 依赖、Wayland/X11 差异)、Windows 特定 GPU 驱动的渲染问题
- **概率** 中 · **影响** 中
- **缓解**:media_kit_libs_video 自带 libmpv 免系统依赖;提供"软件渲染"回退开关(环境变量);问题收集清单持续维护
- ✅ **实测(2026-08-05)**:media_kit_video 2.0.1 存在**创建时序 bug**——`VideoController` 在 `Player.open` 之后创建时,视频帧不渲染(rect 停 1x1 遮挡层不撤),表现为**有声音无画面**(集成测试 `preview_render_check_test.dart` 复现:open 后创建 → 黑屏;先创建后 open → rect 回传 1280x720 正常)。应用曾因"ready 态才创建 VideoController"踩中此 bug,已修复为**面板挂载时(open 前)即创建**(`video_preview_panel.dart` initState)。升级 media_kit_video 前需回归此时序;X11/XWayland 下 H/W 加速仍可能受限(官方 Issue #1359),观测清单持续维护

### R-06 🟡 PlayerController 资源泄漏

- **描述**:多次导入/切换视频后控制器未释放,内存与 GPU 资源泄漏,预览卡顿
- **概率** 中 · **影响** 中
- **缓解**:autoDispose + `ref.onDispose` 强制 dispose;集成测试含"连续切换 10 次视频"用例;内存基线监控(见 [12-开发计划](12-开发计划.md) P7)

### R-07 🟡 ffmpeg_kit 生态的 fork 依赖风险

- **描述**:转码引擎 `ffmpeg_kit_flutter_minimal` 为第三方 fork(原版已停维护),存在后续维护停滞/行为漂移的第三方依赖风险。**已实证**:该 fork 6.0.8 无 Linux/Windows 平台实现(无插件声明、仅 android/ios/macos 目录),桌面真实运行 MissingPluginException —— P1 已按此修订:桌面改走系统 ffmpeg/ffprobe 二进制,Android 保留该 fork(本轮未验证,P8 三平台清单确认)
- **概率** 中 · **影响** 中
- **缓解**:① 版本锁定 ^6.0.8,升级走评审;② P3 阶段做 GIF 转码冒烟验证(GIF 编码是内置组件,预计通过);③ FFmpegEngine/FfprobeExecutor 接口隔离实现,可平移至其他封装;④ **桌面新增系统二进制依赖**:缺失时抛 `FFmpegMissingException`(GIF_127_PROBE_MISSING),P9 打包决策(预检提示/随包携带),开发机需安装 ffmpeg;⑤ iOS 预留场景仍评估原版/mpv/自编译方案
- **预案**:若 fork 停滞 → 评估 `ffmpeg_kit_flutter_new_min`/自编译 FFmpeg FFI,仅重写 FFmpegKitEngine(Android 侧);桌面已不依赖 fork,不受影响

**⚠️ Android 集成实证(2026-08 真机,修复提交见 git log `fix(android)` 系列)**:
- **命令串不得带 `ffmpeg` 可执行名前缀**:`executeAsync` 直接执行 ffmpeg 本体,带前缀时 `ffmpeg` 被当作输出文件名,报 `Unable to choose an output format for 'ffmpeg'`;与桌面 Process 引擎(需前缀)属平台差异,收敛在 `FfmpegKitEngine.assembleCommand`(单测锁定)
- **不支持 `-progress pipe:1`**:ffmpeg-kit 重定向 stdout/stderr,该参数报 `Invalid argument`;进度改用 statistics 回调合成 `-progress` 风格行喂 `ProgressParser`(与桌面解析复用)
- **`MediaInformation.getAllProperties()` 即 ffprobe JSON 原结构**:必须填入 `FfprobeResult.probeJson`,否则业务层兜底报"错误码 0"解析失败
- **logger 包日志在 release 真机不可见**:排查 Android 问题用 `print` 直出 logcat(定位后移除),勿依赖 AppLogger

### R-08 🟢 Windows 打包工具链复杂

- **描述**:NSIS/代码签名/未签名提示等打包与分发环节繁琐
- **概率** 中 · **影响** 低
- **缓解**:flutter_distributor 统一打包;签名证书 V1.0 后评估;安装包冒烟清单化

### R-09 🟢 转码进度解析不准确

- **描述**:部分视频 out_time 更新异常(跳帧/变长帧),进度显示不准确或卡顿
- **概率** 中 · **影响** 低(体验)
- **缓解**:ProgressParser 双源校验(out_time + total_size 降级);UI 节流;显示"速度"辅助判断非死机

### R-10 🟢 竞品替代风险

- **描述**:在线工具/免费替代品抢占用户
- **概率** 中 · **影响** 低(项目为学习/内部工具定位)
- **缓解**:本地优先、无大小限制、批量与历史为差异化;持续跟踪竞品功能

## 13.4 应急预案速查

| 场景 | 动作 |
|------|------|
| 转码挂死无进度 | 10s 无进度更新 → 提示 + 取消按钮(强杀+清理) |
| 磁盘满 | DiskFullException → 提示清理 → 保留半成品?否,清理 |
| 崩溃 | 启动恢复扫描 + crash 日志上报(桌面本地上报文件) |
| 依赖致命不兼容 | 冻结版本回退 → 仓库 issue → 评估替换 |
