## 12.1 计划总览

- 团队规模:1 名开发者 + AI 辅助(Claude Code / DeepSeek)
- 工期估算:单阶段乐观值~保守值;合计 **约 38 天(6–7 周)**
- 里程碑:MVP(P0–P4 + P5)→ V2(P6–P8)→ 发布(P9)
- 依赖关系:P0 前置一切;P1→P2→P3 串行(转换链路);P4 与 P5 可并行;P6 依赖 P3/P4

## 12.3 工作包拆分与执行顺序(分阶段执行依据)

> 每个阶段 = 若干工作包(WP)。**执行规则**:
> 1. 工作包按"顺序"列执行(同序号的为并行窗口,可同时进行)
> 2. 每阶段以**阶段门(Gate)**收尾:验收标准达成 → `flutter analyze`/`test` 全绿 → 提交(`feat/<模块>: 阶段名`)
> 3. 阶段内必须遵守功能层/UI 层分离(先 application 后 presentation,见 [04-系统架构](04-系统架构.md) §4.7)
