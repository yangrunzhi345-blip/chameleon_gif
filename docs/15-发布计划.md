# 15 发布计划

> 开发计划:[12-开发计划](12-开发计划.md) · 测试:[14-测试计划](14-测试计划.md) · V3 扩展:[16-V2.0扩展规划](16-V2.0扩展规划.md)

## 15.1 版本策略

- **语义化版本**:`MAJOR.MINOR.PATCH+build`
  - MAJOR:破坏性变更(架构/存储格式)
  - MINOR:新功能(V2 各期)
  - PATCH:修复
- 发布线:alpha → beta → rc → stable(见 [12-开发计划](12-开发计划.md) §12.4)
- 每版必须:版本号(三平台同步)、CHANGELOG.md、安装包冒烟(14-6 清单)

## 15.2 打包方案(flutter_distributor 统一)

| 平台 | 格式 | 工具 | 产物 |
|------|------|------|------|
| Linux | AppImage + deb | flutter_distributor / appimage 工具链 | `GifForge-<ver>.AppImage`、`.deb` |
| Windows | NSIS 安装包(+zip 便携版) | flutter_distributor | `GifForge-Setup-<ver>.exe` |
| Android | AAB(商店)/ APK(直装) | flutter build appbundle / apk | `app-release.aab` / `.apk` |

- 应用图标、桌面入口(.desktop)、版本元数据在 `linux/`、`windows/`、`android/` 平台工程中维护
- 打包在 CI(标签触发)执行,产物上传发布页/版本管理服务

## 15.3 依赖与 FFmpeg 分发方案

| 项 | 方案 |
|----|------|
| FFmpeg | **随包内嵌,无需用户安装**:`ffmpeg_kit_flutter_minimal` 提供 Linux/Windows/Android 预编译 FFmpeg+FFprobe 原生库,打包时自动进入安装包;预览用 `media_kit_libs_video` 自带 libmpv/FFmpeg |
| 系统依赖 | Linux:除常规 glibc 外无额外依赖(libmpv 内嵌);Windows:无运行时依赖;Android:全内嵌(apk 内 so) |
| 体积 | 预计安装包 40–70MB(播放+转码两套原生库);发布时记录实测 |
| 升级兼容 | 转码库版本升级必须跑"输出一致性"测试(见 [14-测试计划](14-测试计划.md) §14.6) |

## 15.4 版本升级方案

| 平台 | 升级方式 | 说明 |
|------|----------|------|
| Linux | 覆盖安装(deb)/ 替换 AppImage | 数据目录(`~/.local/share/gif_forge`)跨版本兼容 |
| Windows | 安装包覆盖升级 | 保留数据目录;V3 接自动更新 |
| Android | 商店内更新(AAB)/ 直装 APK | versionCode 递增;V3 接自动更新 |

- **数据兼容原则**:Isar 库 schema 变更走迁移(见 [07-数据库设计](07-数据库设计.md) §7.6);旧版本新数据不支持(单向兼容)
- 升级检查:启动时读本地版本文件 vs 最新版本(V3 自动更新接在线检查,预留接口)

## 15.5 发布检查清单(Release Checklist)

- [ ] 版本号三平台一致;CHANGELOG 已更新
- [ ] analyze 零告警;`flutter test` 全绿
- [ ] 三平台手工清单通过(14-6)
- [ ] 输出一致性(SHA-256)验证通过
- [ ] 全新机器安装冒烟:导入→导出→历史→重启持久化
- [ ] 卸载后数据保留策略明确(保留用户数据)
- [ ] 安装包体积与数字签名记录
- [ ] 发布说明(新功能/已知问题/升级注意事项)

## 15.6 发布后监控

- 崩溃日志收集:桌面端本地日志目录 + 用户反馈渠道(V3 接自动上报评审)
- 版本回滚预案:保留上一版安装包;发布异常时公告回滚指引
