## 16.1 规划原则

1. **架构预留不等于提前实现**:本阶段只在现有设计上标记扩展点,不写占位业务代码
2. **每个扩展点必须已在文档中说明**(链接回本文件),实施时按文档执行
3. 扩展按价值排序:先做用户感知强的(编辑/重导出/预设),后做基建的(自动更新)

## 16.3 技术演进路径

### 16.3.1 多语言(i18n)落地步骤

1. 字符串全部收敛到 `lib/app/l10n/`(MVP 期间完成集中化,禁止散落硬编码文案)
2. 引入 `flutter gen-l10n` + ARB(app_zh.arb / app_en.arb)
3. `LocaleController` 三态生效;`MaterialApp.locale` 响应
4. 所有动态文案(错误信息)从异常 `userMessage` 键化

### 16.3.2 插件系统 SPI 草案

```
PluginRegistry(注册)
 ├── ExportFilterPlugin:  参数面板扩展(如新滤镜)→ 注入 GifSetting 扩展字段
 ├── CodecPlugin:         CommandBuilder codec 注册(WebP/APNG 即以此形态)
 └── SourcePlugin:        新输入格式(如 mov/avi)解析器注册
```

- 插件 = Dart 包 + `PluginRegistrar` 接口;隔离于核心,经 provider 注册
- 安全:插件仅运行于 Dart 层,禁止原生代码执行(安全边界)

### 16.3.3 GPU 加速策略

- 探测:PlatformAdapter `hardwareAccelInfo`(vaapi/nvenc 可用性)
- 使用:滤镜复杂(scale/lanczos)适合 GPU;palettegen 仍在 CPU(质量一致性)
- 一致性:GPU 路径输出先过 SHA 校验,不一致自动回退 CPU(质量优先)

### 16.3.4 Web/iOS 平台落地前置条件

| 平台 | 前置条件 |
|------|----------|
| macOS | 签名证书、公证流程、App Sandbox 权限声明 |
| Web | WASM 转码可行性验证(内存上限、包体 ≥15MB 评估)、Isar Web 适配(IndexedDB) |
| iOS | ffmpeg_kit_flutter 评估(停维护风险,见 [13-风险分析](13-风险分析.md) R-07)、沙盒导出流程 |
