## 6.1 模块总览

共 **14 个模块**。原则:**高内聚、低耦合;模块间只通过 Provider 注入的接口通信;模块内部三层(domain 模型/application 用例/presentation UI)可选拆分**。

| # | 模块 | 目录 | 依赖(Domain 接口) | 生命周期 |
|---|------|------|-------------------|----------|
| M01 | Import | features/import | FilePickPort、ParseVideoPort | 常驻 |
| M02 | Preview | features/preview | PlayerPort(media_kit 封装) | 随会话 |
| M03 | Timeline | features/timeline | 无(纯 UI+状态) | 随会话 |
| M04 | Export | features/export | FFmpegEngine、TaskRepository | 随会话 |
| M05 | History | features/history | HistoryRepository | 常驻 |
| M06 | Settings | app/application(features/settings 预留空目录) | SettingsRepository | 常驻 |
| M07 | TaskQueue | features/task_queue | TaskRepository、FFmpegEngine | 常驻(单例) |
| M08 | FFmpeg | features/converter | —(被依赖方) | 常驻 |
| M09 | Storage | shared/repositories | —(Isar/SP 实现) | 常驻 |
| M10 | Log | core/logger | — | 常驻 |
| M11 | Theme | app/theme | SettingsRepository(themeMode) | 常驻 |
| M12 | Localization | app/l10n | SettingsRepository(language) | 常驻(V3 完整) |
| M13 | Camera | features/camera | CameraPort、ParseVideoPort | 随会话 |
| M14 | ScreenRecord | features/screen_record | ScreenRecorderPort、ParseVideoPort | 随会话 |

## 6.1b 模块内两层分离(功能层 / UI 层)

每个 feature 模块内部强制划分为两层(补充要求,红线):

| 层 | 目录 | 包含 | 禁止 |
|----|------|------|------|
| **功能层** | `<模块>/application/` | 用例、控制器(Notifier)、状态逻辑、校验规则 | import material/widgets;感知 Widget 生命周期;直接调仓储(经注入接口) |
| **UI 层** | `<模块>/presentation/` | 页面、组件、模块内路由 | 业务规则、校验/计算、直接调仓储/基础设施 |

- 跨层规则:`presentation → application` 单向;`application` 不得反向依赖 UI。
- "对外接口"列均指 **application 层暴露的控制器/用例**,UI 只消费这些接口(见下表各模块)。
- 判定:功能层代码删除全部 Widget 依赖后仍可编译并可被测试直接调用。

## 6.2 模块职责与边界

### M01 Import 导入模块

- **职责**:file_picker 选文件(MP4 过滤、拖拽);触发视频解析;解析结果(时长/分辨率/帧率)装配为 `VideoInfo` 交给 Preview/Export
- **对外接口**:`ImportController(provider)`: `Future<VideoInfo> import()`;`FilePickPort`: `pickMp4()` / `pickMp4s()`
- **禁止**:不触达 FFmpeg 转码;不做格式嗅探之外的业务
- **模块内**:`application/ImportVideoUseCase`(解析编排)、`presentation/`(按钮/拖拽)

### M02 Preview 预览模块

- **职责**:media_kit `PlayerController` 生命周期管理(创建/销毁);播放/暂停/seek/静音;音量与进度事件流;播放器错误呈现
- **对外接口**:`PreviewController`: `load(VideoInfo)` / `play()` / `pause()` / `seekTo(Duration)` / `dispose()`;`positionStream` / `durationStream`
- **禁止**:不包含时间轴 UI(属 M03);不涉及导出逻辑
- **注意**:PlayerController 是重资源,会话结束必须 dispose(见性能 [13-风险分析](13-风险分析.md) R-06)

### M03 Timeline 时间轴模块

- **职责**:进度条渲染(position/duration);起止标记(两个可拖句柄);标记联动预览(拖动时 seek);选区时长显示;快捷键(空格播放/`I` 设起点/`O` 设终点)
- **对外接口**:`TimelineController`: `RangeSelection {start, end}`;`setStart(Duration)` / `setEnd(Duration)`
- **禁止**:不直接操作 PlayerController(经 PreviewController 的公开方法);不生成 FFmpeg 参数(参数装配归 Export)

### M04 Export 导出模块

- **职责**:参数面板状态(FPS/尺寸/起止/目录/循环);参数校验与钳制;装配 `GifSetting`;调用 TaskQueue 发起任务;进度展示(订阅 TaskProgress);完成/失败提示;导出目录选择(file_selector)
- **对外接口**:`ExportController`: `submit(GifSetting)` / `cancelTask(id)`;`progressStream`
- **禁止**:不直接调用 FFmpegEngine(一律经 TaskQueue 调度);不写历史记录(完成回调由 TaskQueue 落 History)

### M04b 图片制作会话(app 层组合,多图合成 GIF)

> 图片模式与视频模式并列,会话控制器与页面壳驻留 `app/application` / `app/presentation`
>(跨模块组合收敛于 app 层,与 [05-目录结构](05-目录结构.md) 口径一致)。

- **职责**:图片列表会话(选择/排序/删除/追加);参数表单(帧率/每图停留时长/宽高/循环/质量/目录);首图尺寸探测(倍数联动/画布);装配 `GifSetting + ImageGifSource`(含 `perImageControls`)→ 经 TaskQueue 入队;完成/失败提示;**每图精细控制**:齿轮入口 → 全屏控制页(`/image-control`,单图倍率/宽度/高度,实时预览、保存 pop 返回、恢复默认)
- **对外接口**:`ImageGifController`: `init()` / `updatePaths(paths)` / `submit(paths, {perImageControls})` / `update*(表单)`;`canvasSize`(画布推导,预览用);`ImageControlScreen`(路由页)
- **禁止**:UI 层不承载业务计算(画布/控制目标计算在 `ImageGifController.canvasSize` 与 `converter/application/control_target.dart`);不直调仓储

### M05 History 历史模块

- **职责**:历史列表(时间倒序、分页);详情页(参数快照/大小/耗时);重转(重新加载到 Export);删除/清空
- **对外接口**:`HistoryController`: `list()` / `delete(id)` / `clear()`;`HistoryRepository`
- **禁止**:不感知转换中任务(只读已完成的不可变快照)

### M06 Settings 设置模块

- **职责**:偏好页面(主题/语言/默认导出目录/默认参数);读改写 `SettingsRepository`;变更即广播(主题/语言立即生效);相机/录屏参数分组(`CameraSettingsController`/`RecordSettingsController`)与采集素材存储管理(`CacheStorageController`/`CapturesStorageController`)也驻留 app/application
- **对外接口**:`SettingsController`: `themeMode` / `locale` / `defaultExportDir` / `defaultGifSetting`
- **目录口径**:`features/settings` 为预留空目录,实际实现收敛于 `app/application` 会话控制器与 `app/presentation/settings_screen.dart`(跨模块设置组合归 app 壳)
- **禁止**:不存储任务/历史(结构化数据归 Isar,见 [07-数据库设计](07-数据库设计.md))

### M07 TaskQueue 任务队列模块 ⭐

- **职责**(只调度,不转码):
  - 任务状态机:`queued → running → completed | failed | cancelled`(见 §6.3)
  - 并发上限(默认 2);FIFO + 优先级(手动置顶);取消语义(已排队→直接取消;运行中→通知 Converter 终止)
  - 失败重试:最多 2 次,指数退避(2s/4s);重试只对可重试错误
  - 持久化:任务入库(Isar),应用重启恢复未完成任务(见 [07-数据库设计](07-数据库设计.md) 生命周期)
- **对外接口**:`TaskQueueController`: `submit(GifSetting, VideoInfo) → taskId` / `cancel(taskId)` / `retry(taskId)`;`taskStream`(全量状态流)
- **禁止**:不构造命令、不执行 FFmpeg(委托 M08);不落历史(完成后通知 History 模块经用例)
- **并发模型**:单 isolate 内异步;FFmpeg 子进程由 M08 管理

### M08 FFmpeg 转换模块 ⭐

- **职责**:见 [08-FFmpeg设计](08-FFmpeg设计.md)。对外暴露 `FFmpegEngine` 接口:命令构造(CommandBuilder)→ 执行(FFmpegKitEngine)→ 进度解析(ProgressParser)→ 错误分类(ErrorHandler)→ 取消(CancellationManager)
- **对外接口**:`FFmpegEngine.convert(ConvertRequest, {onProgress, onLog, cancelToken}) → Future<ConvertResult>`
- **禁止**:不做调度决策;不感知"用户按了几次导出"

### M09 Storage 存储模块

- **职责**:Isar 实例初始化与关闭;集合访问器(Tasks/History/Presets);SharedPreferences 键值访问;仓储实现类(实现 domain 接口)
- **对外接口**:`isarProvider` / `taskRepositoryProvider` / `historyRepositoryProvider` / `settingsRepositoryProvider`
- **禁止**:不包含业务规则

### M10 Log 日志模块

- **职责**:AppLogger 封装(级别过滤、console/file 双通道、导出任务独立日志文件、崩溃转储)。设计见 [11-开发规范](11-开发规范.md) 日志章节
- **禁止**:不打印业务告警以外的敏感信息(路径可记录,内容截断)

### M11 Theme 主题模块

- **职责**:Material 3 主题构建(`ColorScheme.fromSeed`);深色/浅色/跟随系统三态;高对比度跟随系统
- **对外接口**:`ThemeController`: `themeMode`;`themeData`
- **禁止**:不包含业务状态

### M12 Localization 本地化模块

- **职责**:三态语言(跟随系统/中文/English);V3 完整化;MVP 阶段只搭骨架(字符串集中常量,预留 ARB)
- **对外接口**:`LocaleController`

### M13 Camera 相机拍摄模块(已实现,见 [18-相机拍摄开发计划](18-相机拍摄开发计划.md)/[20-拍摄录屏合并执行方案](20-拍摄录屏合并执行方案.md))

- **职责**:调用设备相机录制短视频,产物 MP4 自动导入(复用 ParseVideoPort → /preview);桌面 ffmpeg 采集(v4l2/dshow,命令构造纯函数 `CameraCommandBuilder`,支持时长上限与实时预览)、Android 走 camera 插件(CameraX);桌面相机参数经 v4l2-ctl 探测与解析
- **对外接口**:`CameraPort`(domain 端口): `start(CaptureParams)` / `stop()` / 进度与状态流;会话编排在 `app/application/capture_session_controller.dart`
- **禁止**:不感知下游转换链路(产物路径经 `CaptureImportUseCase` 移交);不写历史(完成由导入链路落 History)

### M14 ScreenRecord 屏幕录制模块(已实现,见 [19-录屏开发计划](19-录屏开发计划.md)/[20-拍摄录屏合并执行方案](20-拍摄录屏合并执行方案.md))

- **职责**:录制屏幕画面(全屏/框选区域),产物 MP4 自动导入;桌面 ffmpeg 采集(x11grab/gdigrab;Wayland 自动探测切换 wf-recorder,`RecordEnvironmentDetector`)、Android 走 MediaProjection 原生 MethodChannel(`ScreenRecordChannel`/`ScreenRecordService`);桌面框选区域经 window_manager 全屏遮罩(`region_overlay_math` 几何换算)
- **对外接口**:`ScreenRecorderPort`(domain 端口): `start(RecordParams)` / `stop()`;会话编排在 `app/application/record_session_controller.dart`
- **禁止**:同 M13——不感知下游转换,不写历史

## 6.3 任务状态机(TaskQueue 模块)

```
                  提交                      开始执行
   ┌────────┐ ──────▶ ┌────────┐ ────────▶ ┌────────┐
   │  idle  │          │ queued │           │ running │
   └────────┘          └────────┘           └────┬───┘
       ▲                  │  取消/会话退出        │
       │                  ▼                      │ 成功
       │             ┌─────────┐        ┌───────▼───────┐
       │  重试≤2次    │ cancelled│        │  completed    │ ──▶ 写历史+通知
       │  ◀─────────  └─────────┘        └───────┬───────┘
       │                                          │ 失败
       │                          ┌───────────────▼──┐
       └──────────────────────────│  failed(可重试)  │
                                  └──────────────────┘
```

- `queued` 状态持久化 → 崩溃恢复:重启后重新排队(见 4.4 节)
- `cancelled` 与 `completed` 为终态;`failed` 可重试(重试后回到 `queued`)

## 6.4 模块通信方式

| 方式 | 场景 | 说明 |
|------|------|------|
| Provider 注入(直接调用) | 用例之间 | 跨模块调用接口,编译期安全 |
| Stream 事件 | 进度/位置/状态广播 | TaskQueue→Export、Preview→Timeline |
| 回调 | 一次性结果 | FFmpegEngine.onProgress / onLog |
| Notifier 状态 | UI 状态读取 | AsyncValue 驱动 |

**禁止**:模块间通过全局静态变量、单例服务定位器、消息总线(事件风暴)耦合。
