# 07 数据库设计

> 模块设计:[06-模块设计](06-模块设计.md) · 状态管理:[09-状态管理](09-状态管理.md) · 数据模型详见本文档 §7.3

## 7.1 存储边界(什么放哪里)

| 存储 | 用途 | 理由 |
|------|------|------|
| **Isar(结构化)** | ExportTask、ExportHistory、ExportPreset | 需查询/索引/关系/批量操作 |
| **SharedPreferences(KV)** | 主题、语言、最近导入目录、默认导出目录 | 高频读、无查询需求 |
| **配置文件(JSON,预留)** | 导出预设导入/导出、插件配置(V3) | 需随包分发、用户可编辑 |
| **内存(不持久化)** | 播放位置、表单输入、未提交的临时状态 | 会话态,见 [09-状态管理](09-状态管理.md) §9.4 |

## 7.2 数据库选型确认

- Isar 3.1.0(官方稳定版);禁止 4.0-dev(见 [13-风险分析](13-风险分析.md) R-04)
- 索引策略:查询频率高的字段建索引(createdAt、taskId),写入频率高的字段不建
- 单实例打开:`Isar.open([TaskSchema, HistorySchema, PresetSchema], directory: ...)`

## 7.3 集合(Collection)设计

### 7.3.1 `ExportTask` — 转换任务(临时/状态流)

> 生命周期:提交时创建 → 转换中更新状态与进度 → 终态后**默认保留 30 天**(可配),完成后生成 History 快照即可由用户清理。崩溃恢复依据。

| 字段 | 类型 | 说明 | 索引 |
|------|------|------|------|
| `id` | int | 自增主键 | ✅ 主键 |
| `videoPath` | String | 源文件绝对路径 | |
| `outputPath` | String? | 输出目标路径(完成后非空) | |
| `settingsJson` | String | GifSetting 的 JSON 快照(Freezed toJson) | |
| `state` | `TaskState`(enum 存 int) | idle/queued/running/completed/failed/cancelled | ✅ |
| `progress` | double | 0.0–1.0 | |
| `errorCode` | String? | 失败错误码(见 [08-FFmpeg设计](08-FFmpeg设计.md) §8.6) | |
| `errorDetail` | String? | 错误详情(截断 500 字符) | |
| `retryCount` | int | 已重试次数(≤2) | |
| `createdAt` | DateTime | 创建时间 | ✅ |
| `startedAt` | DateTime? | 开始执行时间 | |
| `finishedAt` | DateTime? | 终态时间 | |

**生命周期**:`queued→running→(completed|failed|cancelled)`(状态机见 [06-模块设计](06-模块设计.md) §6.3)。崩溃恢复:启动时扫描 `state ∈ {queued, running}` 的任务,重置为 `queued` 重新排队;`running` 的残留进程由其 CancellationManager 兜底清理。

### 7.3.2 `ExportHistory` — 历史记录(永久/不可变快照)

> 生命周期:任务 completed 时生成,不可变更;用户可删除/清空。用于历史列表、详情、重转。

| 字段 | 类型 | 说明 | 索引 |
|------|------|------|------|
| `id` | int | 自增主键 | ✅ 主键 |
| `videoPath` | String | 源文件路径 | |
| `outputPath` | String | 输出 GIF 路径 | |
| `settingsJson` | String | GifSetting 快照 | |
| `durationMs` | int | 转码耗时(ms) | |
| `outputSizeBytes` | int | 输出文件大小 | |
| `createdAt` | DateTime | 完成时间 | ✅(列表排序) |
| `sourceDurationMs` | int | 源时长(详情展示) | |
| `outputFrameCount` | int | 输出帧数(可空) | |

### 7.3.3 `ExportPreset` — 预设(可复用模板)

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | int | 自增主键 |
| `name` | String | 预设名(唯一约束) |
| `settingsJson` | String | GifSetting 快照 |
| `createdAt` | DateTime | 创建时间 |

> 预设"重名覆盖"语义:业务层查重后删除旧行再插入(Isar 无唯一索引约束时用事务)。

### 7.3.4 `AppSetting` — 偏好 KV(存 SharedPreferences,非 Isar)

| Key | 类型 | 默认 | 说明 |
|-----|------|------|------|
| `theme_mode` | String | `system` | light/dark/system |
| `language` | String | `system` | system/zh/en |
| `last_import_dir` | String | 用户目录 | 文件选择器初始目录 |
| `default_export_dir` | String | 用户目录/Downloads | 导出默认目录 |
| `default_fps` | int | 15 | 默认帧率 |
| `default_width` | int | 0 | 默认宽度(0=原图等比) |
| `default_loop` | int | 0 | 默认循环次数(0=无限) |
| `history_retention_days` | int | 30 | 历史/任务保留天数 |

## 7.4 数据模型(Freezed 定义草案)

> 代码生成:freezed + json_serializable + isar_community_generator(import `package:isar_community/isar.dart`,见 [03-技术选型](03-技术选型.md) Isar 行)。以下为字段契约,实施时以 dart 为准。

### `VideoInfo`(Domain 实体,非持久化)

```
class VideoInfo {
  final String path;          // 源路径
  final String fileName;      // 显示名
  final Duration duration;    // 总时长
  final int width;            // 源宽
  final int height;           // 源高
  final double fps;           // 源帧率(ffprobe 解析)
  final int sizeBytes;        // 文件大小
  final String codec;         // 视频编码(如 h264)
  final bool hasAudio;        // 是否含音轨
}
```

### `GifSetting`(值对象,V2 全字段,MVP 子集)

```
class GifSetting {
  final double fps;               // 输出帧率 1–60
  final int width;                // 输出宽度(0=原图等比)
  final Duration start;           // 起止
  final Duration end;
  final int loop;                 // 0=无限
  final PaletteMode palette;      // off/global(默认 global)
  final DitheringMode dithering;  // none/diffusion/standard
  final int colorCount;           // 256/128/64/32
  final double speed;             // 0.25–4
  final bool reverse;             // 倒放
  final MirrorMode mirror;        // none/h/v
  final Rotation rotation;        // 0/90/180/270
  final Rect? cropRect;           // 裁剪(V2)
}
```

### `TaskState`(enum)

```
enum TaskState { idle, queued, running, completed, failed, cancelled }
```

### `TaskProgress`(值对象,流式)

```
class TaskProgress {
  final int taskId;
  final double percent;     // 0.0–1.0
  final Duration elapsed;
  final Duration remaining; // 预估
  final double speedKbPerSec;
}
```

### `ExportTask` / `ExportHistory` / `ExportPreset`

Isar 集合注解(`@Collection` / `@Index`),字段同 §7.3,`settingsJson` 经 GifSetting 的 `toJson/fromJson`(Freezed 生成)互相转换。

## 7.5 序列化方式

| 对象 | 序列化 | 说明 |
|------|--------|------|
| GifSetting | Freezed `toJson/fromJson` | 存入 settingsJson 字段 |
| ExportTask 等 | Isar 原生(字段级) | 枚举以 int 存(`state.index`) |
| 配置 KV | 原生类型 | SharedPreferences 直接存 |

**版本兼容**:GifSetting 升级(V2 新增字段)时 `fromJson` 对缺失字段给默认值(Freezed 的 `@Default`),保证老历史记录可读。

## 7.6 迁移与备份

- Isar 3.x 无自动 schema 迁移 → 集合结构变更时按版本迁移:检测 `isar.schemaVersion` 不匹配 → 备份旧库(复制文件)→ 重建 → 从 JSON 恢复可读字段
- 备份目录:`<appData>/backup/`,保留最近 3 份
- MVP 阶段结构冻结:所有字段必须经评审再变更(见 [13-风险分析](13-风险分析.md) R-04)
